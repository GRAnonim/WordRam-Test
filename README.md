# WordRam — Веб-игра в слова (Филворды / Snaking Word Puzzle)

**WordRam** — это увлекательная игра-головоломка на сетке 5×5 (25 ячеек) с механикой поиска спрятанных английских слов по ломаным маршрутам («змейкам»).

---

## 🎮 Игровые правила

1. **Соседние клетки (Манхэттенское расстояние = 1):** Соединение букв возможно только по вертикали и горизонтали (вверх, вниз, влево, вправо). Диагонали и перескоки через ячейки запрещены.
2. **Ломаные маршруты («змейки»):** Слова не располагаются по прямой линии — генератор гарантирует наличие минимум 1–3 поворотов в зависимости от сложности уровня.
3. **Без повторов:** Одна ячейка не может использоваться дважды в рамках одного слова.
4. **Поиск вслепую:** Список искомых слов скрыт над игровым полем — игрок видит только количество слов и их длины (слоты).
5. **Двусторонний ввод:** Слова можно проводить как от первой буквы к последней, так и в обратном порядке.
6. **Пошаговая подсказка:** Кнопка «💡 Подсказка» последовательно подсвечивает буквы ненайденного слова: 1-й клик — первая буква, 2-й клик — вторая буква и т.д.
7. **Бонусные слова:** Нахождение дополнительных скрытых слов словаря на поле приносит бонусные монеты (+2 🪙).

## 📁 Структура файлов проекта (Flat Root Structure)

Все файлы расположены в корне репозитория для бесшовного деплоя на GitHub Pages:

- `index.html` — главная разметка с поддержкой PWA (`lang="ru"`, метатеги для iOS Safari).
- `styles.css` — стили, светлая/темная тема, адаптивная верстка, анимации ячеек и слотов.
- `data.js` — словарь английских слов (3–8 букв), распределение частот букв, темы и конфиги уровней.
- `storage.js` — модуль сохранения в `localStorage` (уровни, звезды, монеты, подсказки, ежедневный стрик).
- `generator.js` — алгоритм генерации ломаных маршрутов слов, пересечений, дистракторов и расчет сложности.
- `game.js` — игровое ядро, обработка жестов (тач/мышь), пошаговые подсказки, звуковой синтез Web Audio API.
- `main.js` — переключение 4 вкладок меню («Игра», «Уровни», «Сегодня», «Настройки»), модальные окна победы.
- `manifest.webmanifest` — PWA манифест для установки игры на главный экран смартфона.
- `sw.js` — Service Worker с версией кэша `wordram-v5` для надежной оффлайн-работы.
- `test-generator.mjs` — автоматический тест генерации 300+ уровней.

## 🚀 Запуск и тестирование

### Локальный запуск
Открыть `index.html` в любом современном браузере или запустить через локальный сервер:
```bash
npx serve .
```

### Автоматическое тестирование генератора
```bash
node test-generator.mjs
```

## 🌐 Деплой на GitHub Pages

1. Склонируйте репозиторий или загрузите все файлы в корень ветки `main`.
2. В настройках репозитория перейдите в **Settings** ➔ **Pages**.
3. В секции **Build and deployment** выберите Source: **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**.
4. Игра станет доступна по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
